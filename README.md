# Вместе

Первая версия приложения для пары. Общий кошелёк и личные кошельки, регистрация, приглашение второго участника, доходы и расходы в рублях, категории, месячные отчёты с диаграммой. Личные записи отбираются на сервере по владельцу. Суммы хранятся в копейках. Общие данные обновляются каждые 15 секунд, пока приложение открыто.

## Локальный запуск

Требуется Node.js 24. В папке проекта выполните `node server.mjs`, затем откройте http://127.0.0.1:8080. Поле адреса сервера оставьте пустым. Для проверки пары используйте два разных профиля браузера. Данные сохраняются в `data/budget.sqlite`. Проверка серверных сценариев запускается командой `node --test test/*.test.mjs`.

## Сервер

На сервере с Docker выполните `docker compose up -d --build`. Приложение слушает только 127.0.0.1:8080. Настройте внешний reverse proxy с HTTPS на этот порт. В Android-приложении укажите HTTPS-адрес домена. Сохранность данных обеспечивается томом `budget-data`. Резервное копирование и восстановление базы нужно настроить перед использованием реальных данных. Доступ к данным сервера имеет его администратор.

## Android

Откройте папку `android` в Android Studio. Для сборки нужны JDK 17, Android SDK 35 и Gradle 8.11.1. Если Gradle установлен отдельно, запустите из папки `android` команду `gradle assembleDebug`. APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Интерфейс включён в APK и загружается через WebViewAssetLoader. Сервер задаётся на экране входа.

## Статус

Тестовый APK собран 4 ноября 2026 года и сохранён в `dist/together-0.1.0.apk`. Сборка Gradle успешна, HTTP-тест приглашений, приватности, валидации и повторной отправки операций пройден. В APK проверено наличие интерфейса и Android-компонентов. На Android-устройстве приложение ещё не проверялось. Браузерная визуальная проверка через встроенный инструмент завершилась тайм-аутом. HTTPS GET с компьютера возвращает 200.

Сервер работает в Docker на Ubuntu в `/home/pigsuvskrot/pair-budget`. Адрес приложения — https://budget.158-160-250-19.sslip.io. Временный домен зависит от DNS-сервиса sslip.io. Caddy выпускает сертификат автоматически. Для запуска с существующей сетью Caddy используется `docker compose -f compose.yaml -f compose.server.yaml up -d --build`. Исходная конфигурация Caddy сохранена на сервере в `/opt/portal/Caddyfile.before-budget`.

Операции доступны при подключении к серверу. Редактирование и удаление операций, восстановление пароля и управление выходом из пары пока не реализованы. Название «Вместе» и валюта RUB выбраны для первой версии. APK подписан тестовым ключом временного сборочного контейнера. Перед следующей распространяемой сборкой нужно настроить постоянный ключ подписи. Обновление текущего тестового APK может потребовать переустановки, при этом данные аккаунта сохраняются на сервере. Резервное копирование базы пока не настроено.

Использованы официальные руководства [Android WebViewAssetLoader](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content) и [Node SQLite](https://nodejs.org/api/sqlite.html).
